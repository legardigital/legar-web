# legAR · Web

Sitio de legAR (antes Diligencias La Plata), publicado en Netlify.

- `index.html`: solapa legAR (inicio)
- `gestoria.html`: Gestoría
- `marketing.html`: Marketing jurídico
- `novedades.html`: Novedades y valores de referencia (JUS, UMA, aranceles)

Cada cambio en la rama `main` se publica automáticamente en Netlify.
